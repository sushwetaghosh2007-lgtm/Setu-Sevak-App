# Setu Sevak

A web platform designed to streamline access to essential public services, welfare schemes, and document management.

## Tech Stack
* **Backend**: Python, FastAPI, Uvicorn, Pydantic
* **Frontend**: HTML5, JavaScript, CSS3

## How to Run
1. Install dependencies: `pip install fastapi uvicorn pydantic`
2. Start backend server: `python backendseva.py`
3. Open `updatedhtml.html` in your browser or serve via `python -m http.server 5500`
